# Task 28 – Simple Percentage Analysis

## Objective
Calculate contribution percentages by category using Excel and a Superstore-style sample sales dataset.

## Tools
- Microsoft Excel
- GitHub

## Files
- `Task-28-Simple-Percentage-Analysis.xlsx` – Excel workbook with raw data, percentage table, formulas, KPI checks, and chart.
- `superstore_sample_sales.csv` – source data used in the workbook.
- `category_contribution_chart.png` – chart for the GitHub project README.
- `README.md` – project documentation.

## Formula Used
**Contribution % = Category Sales / Total Sales**

The denominator is explicitly shown as the **Grand Total Sales** so the percentage is easy to interpret.

## Validation
The category contribution percentages sum to **100%** (or 1.00 in Excel), confirming that the category shares cover the full sales total.

## Result
This project demonstrates a basic business-reporting technique for understanding how much each category contributes to overall sales.

## Excel Structure
**Raw_Data** contains Order ID, Category, Sub-Category, and Sales.

**Percentage_Analysis** contains:
- Category sales
- Contribution percentage
- Grand Total
- Denominator
- KPI checks
- Contribution chart

## Dataset Note
The CSV is a small, synthetic Superstore-style dataset created for practice and portfolio demonstration. It is not an official Tableau Sample - Superstore file.
